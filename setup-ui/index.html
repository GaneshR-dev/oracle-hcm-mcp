1. Target

Choose where the MCP will talk. Dummy HCM is the local mock (npm run dummy-hcm on :9090).

2. Base URL & API version

Resources path becomes {base}/resources/{version}/…. Profiles are labels for your own mcp.json copies.

3. Authentication

Credentials open the HTTP door; HCM RBAC still applies. Secrets stay in this browser until you generate config or optionally write .env.local.

4. Write safety

5. Test connection

The setup server proxies a cheap workers?limit=1 probe. It never returns or logs your password / token / client secret.


      


      
      

        
6. Cursor mcp.json

        
Copy into Cursor MCP settings. Two servers: safe default (oracle-hcm) and unrestricted writes (oracle-hcm-write). Secrets are embedded only in what you copy — the setup server does not store them.

        

          
          
        

        

        

      


      
      

        
7. How to use

        

          
Local dummy

          
npm run dummy-hcm
# then point MCP at http://127.0.0.1:9090/hcmRestApi (demo/demo)

          
Run MCP (stdio)

          
npm run build
npx oracle-hcm-mcp
# or: node dist/index.js --base-url http://127.0.0.1:9090/hcmRestApi
